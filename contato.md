# Contato

Use este canal para dúvidas de implementação, alinhamento de contrato e acompanhamento de mudanças da API.

## Canal principal

- Slack: canal `desenvolvimento`

## Quando usar

- Dúvidas sobre contrato da API
- Divergência entre documentação e resposta real
- Ajustes de integração do frontend
- Problemas de autenticação, formato ou comportamento inesperado

## Quando abrir issue

Abra uma GitHub Issue quando houver:

- Bug reproduzível
- Mudança de contrato que precisa ficar registrada
- Falha de documentação que impacta a integração

## Boas práticas de suporte

- Inclua endpoint, payload, status HTTP e `error.code`.
- Anexe exemplo de resposta sempre que possível.
- Informe o contexto de ambiente: local, Docker, homologação ou produção.
